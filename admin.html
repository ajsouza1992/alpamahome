O que você cadastra fica salvo como rascunho neste navegador. Para todo mundo ver:

  1. Confira com Ver site.
  2. Clique em Baixar produtos.js.
  3. No GitHub, substitua o arquivo produtos.js pelo baixado (Add file → Upload files → Commit changes).
  4. Em 1–2 minutos o site atualiza.
